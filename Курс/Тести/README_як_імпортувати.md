# Тести курсу: як користуватися

## Склад

- `Тест_1.md` … `Тест_8.md` — тести у читабельному вигляді. Правильні відповіді
  позначені як `- [x]`, неправильні — `- [ ]`.
- `Тести_GIFT.txt` — ті самі 80 питань у форматі Moodle GIFT, готові до імпорту.
- `md2gift.py` — скрипт перетворення Markdown у GIFT.

## Імпорт у Moodle

1. Курс → **Банк питань** → **Імпорт**.
2. Формат файлу: **GIFT format**.
3. Кодування: **UTF-8**.
4. Завантажити `Тести_GIFT.txt` → **Імпорт**.

Питання автоматично розкладуться по категоріях з назвами тестів
(«Тест 1. Континуум віртуальності» і т. д.). Далі в кожному тесті
обирається потрібна категорія й додаються всі питання.

## Як вносити зміни

Правити слід **файли .md**, а не GIFT. Після правок виконати:

```
python3 md2gift.py
```

Скрипт перебере всі файли `Тест_*.md` і перезапише `Тести_GIFT.txt`.
Якщо в якомусь питанні забуто позначити правильну відповідь, скрипт
повідомить про це із зазначенням номера питання.

## Як додати нове питання

Дописати у відповідний файл блок такого вигляду:

```
### 11. Текст питання
- [ ] неправильний варіант
- [x] правильний варіант
- [ ] неправильний варіант
```

Якщо позначити кілька варіантів як `[x]`, питання автоматично стане
питанням із кількома правильними відповідями: бали розподіляться
порівну між правильними, за кожну хибну знімається 100 %.

## Рекомендовані налаштування тесту в Moodle

- Перемішування питань і варіантів відповідей — увімкнути.
- Кількість спроб — 2–3, оцінка за найвищою спробою.
- Обмеження часу — 10–15 хвилин на 10 питань.
- Відгук — показувати після закриття тесту, щоб уникнути передавання відповідей.
