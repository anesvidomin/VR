# Лабораторна робота № 4
## Підготовка та оптимізація BIM-моделі Revit для віртуальної реальності

**Тема:** 5 (3D-моделі та формати обміну даними)
**Тривалість:** 4 години

### Мета роботи

Навчитися готувати BIM-модель до використання у віртуальній реальності: виконувати експорт у різні формати, оцінювати втрати даних, виконувати оптимізацію геометрії та контролювати продуктивність отриманої сцени.

### Обладнання та програмне забезпечення

- Комп'ютер, шолом Meta Quest 3
- Autodesk Revit
- Програма перегляду моделей (Navisworks, Autodesk Viewer або безкоштовний переглядач IFC)
- Unity або Twinmotion для перевірки продуктивності

### Короткі теоретичні відомості

BIM-модель створюється для отримання креслень і специфікацій, тому містить максимум деталей, у тому числі невидимих. Для віртуальної реальності вимоги протилежні: сцена має малюватися 72–90 разів на секунду, причому окремо для кожного ока. Пряме завантаження неоптимізованої моделі у шолом призводить до різкого падіння частоти кадрів і дискомфорту користувача. Саме тому підготовка моделі є обов'язковим етапом роботи.

### Вихідні дані

Модель фрагмента будівлі в Revit (власна курсова робота або надана викладачем), що містить архітектурну та конструктивну частини, бажано з інженерними мережами.

### Порядок виконання роботи

**Завдання 1. Аналіз вихідної моделі**

1. Відкрити модель у Revit. Зафіксувати: розмір файлу, кількість елементів, склад розділів.
2. Визначити, які елементи не будуть видимі під час огляду у VR (арматура, внутрішні шари конструкцій, кріплення, фундаменти нижче рівня землі).

**Завдання 2. Експорт у різні формати**

3. Виконати експорт моделі у три формати: **IFC**, **FBX**, **glTF (або OBJ)**.
4. Для кожного файлу зафіксувати в таблиці: розмір файлу, час експорту.
5. Відкрити кожен файл у переглядачі й перевірити, що збереглося:
   - геометрія;
   - матеріали;
   - інформація про елементи (тип, матеріал, властивості);
   - структура моделі за розділами.
6. Заповнити порівняльну таблицю втрат.

**Завдання 3. Перевірка типових помилок імпорту**

7. Імпортувати файл FBX в Unity або Twinmotion. Перевірити:
   - масштаб (поставити поруч об'єкт заввишки 1,75 м);
   - орієнтацію (чи не перевернута модель);
   - положення відносно початку координат.
8. Якщо модель розташована далеко від початку координат — виправити це в Revit (перенести в початок координат) і повторити експорт. Зафіксувати різницю.

**Завдання 4. Оптимізація моделі**

9. Створити у Revit окремий вид для експорту у VR, вимкнувши в ньому невидимі категорії елементів.
10. Виконати експорт із цього виду.
11. Зафіксувати нові показники: розмір файлу, кількість полігонів.
12. За потреби виконати додаткове спрощення геометрії у проміжній програмі.

**Завдання 5. Контроль продуктивності**

13. Завантажити у сцену обидва варіанти моделі — вихідний і оптимізований.
14. Для кожного зафіксувати: кількість трикутників, кількість матеріалів, частоту кадрів у шоломі.
15. Заповнити підсумкову таблицю «було / стало».
16. Зробити висновок, чи відповідає оптимізований варіант вимогам автономного режиму Quest 3 (до 1 млн трикутників у кадрі).

**Завдання 6. Вибір формату під задачу**

17. Обґрунтувати, який формат слід обрати для кожного випадку:
    - передача моделі замовнику для перегляду;
    - перевірка колізій із збереженням даних про елементи;
    - створення інтерактивного застосунку в Unity.

### Зміст звіту

1. Тема, мета, вихідні дані (опис моделі).
2. Таблиця порівняння форматів експорту із зазначенням втрат.
3. Опис виявлених помилок імпорту та способів їх усунення.
4. Перелік елементів, виключених з експорту, з обґрунтуванням.
5. Підсумкова таблиця «було / стало»: розмір файлу, полігони, матеріали, частота кадрів.
6. Знімки екрана вихідного та оптимізованого варіантів.
7. Висновки з обґрунтуванням вибору формату під конкретні задачі.

### Контрольні питання

1. Чому BIM-модель не можна напряму завантажити в автономний шолом?
2. Що втрачається при експорті у FBX і що зберігається при експорті в IFC?
3. Чому модель після імпорту може мати неправильний масштаб?
4. Чому модель у геодезичних координатах потрібно перенести в початок координат?
5. Які елементи моделі доцільно виключити перед експортом у VR?
6. Скільки часу відведено на побудову одного кадру при частоті 90 Гц?

### Критерії оцінювання

| Критерій | Балів |
|---|---|
| Виконано експорт у три формати з порівняльним аналізом | 3 |
| Виявлено та усунуто помилки імпорту | 2 |
| Виконано оптимізацію з вимірюваним результатом | 3 |
| Оформлено звіт із таблицями й висновками | 2 |
| **Разом** | **10** |
