# Лабораторна робота № 2
## Ескізування об'ємного рішення у віртуальній реальності (Gravity Sketch)

**Тема:** 1, 4 (сприйняття простору)
**Тривалість:** 4 години

### Мета роботи

Освоїти створення об'ємних ескізів безпосередньо у віртуальному середовищі в масштабі 1:1, порівняти цей спосіб роботи з традиційним ескізуванням на папері та в CAD, експортувати результат для подальшої роботи.

### Обладнання та програмне забезпечення

- Шолом Meta Quest 3 (застосунок працює автономно, комп'ютер не потрібен)
- Gravity Sketch (безкоштовна версія для індивідуального використання)
- Альтернатива: Open Brush — безкоштовний, простіший
- SketchUp або Revit для перевірки експортованої моделі

### Короткі теоретичні відомості

Ескізування у віртуальній реальності принципово відрізняється від малювання на папері: автор одразу працює в натуральну величину й бачить результат з позиції людини, яка перебуватиме всередині об'єкта. Це дозволяє на ранній стадії оцінити пропорції й масштаб, які на папері залишаються абстрактними. Такий спосіб застосовують на етапі пошуку концептуального рішення, до переходу в BIM-програму.

### Завдання на проєктування

Обрати один об'єкт:
- навіс або зупинковий комплекс;
- вхідна група громадської будівлі;
- малі архітектурні форми для подвір'я;
- альтанка, бесідка, оглядовий майданчик;
- фрагмент фасаду (ритм отворів, сонцезахист).

### Порядок виконання роботи

**Завдання 1. Освоєння інструментів**

1. Запустити Gravity Sketch, пройти вступне навчання.
2. Освоїти базові інструменти: лінія, об'єм (примітиви), поверхня, переміщення, масштабування, копіювання.
3. Освоїти зміну масштабу сцени: перегляд «згори, як макет» і перегляд «зсередини, у натуральну величину».

**Завдання 2. Ескіз на папері (контрольний)**

4. До початку роботи у VR зробити звичайний ескіз обраного об'єкта на папері з основними розмірами. Витратити не більше 15 хвилин.
5. Сфотографувати ескіз для звіту.

**Завдання 3. Побудова у VR**

6. Створити об'ємне рішення обраного об'єкта у VR.
7. Витримати реальні габарити: висота проходу не менше 2,2 м, ширина не менше 1,2 м, висота огорожі 1,1 м.
8. Для контролю масштабу поставити у сцені фігуру людини або орієнтир відомої висоти.
9. Виконати не менше двох варіантів рішення.

**Завдання 4. Оцінка зсередини**

10. Перейти в масштаб 1:1 і пройти створеним об'єктом.
11. Оцінити: чи достатня висота, чи зручний прохід, чи не тисне конструкція, як сприймаються пропорції.
12. Внести виправлення за результатами огляду. Зафіксувати, що саме довелося змінити — це головний результат роботи.

**Завдання 5. Експорт**

13. Експортувати модель (OBJ або FBX).
14. Відкрити її в SketchUp або Revit. Перевірити масштаб і орієнтацію.
15. Зафіксувати, що збереглося при експорті, а що втратилося.

**Завдання 6. Порівняння способів роботи**

16. Заповнити таблицю порівняння ескізування на папері та у VR:

| Критерій | На папері | У VR |
|---|---|---|
| Час на отримання першого варіанта | | |
| Точність габаритів | | |
| Оцінка пропорцій і масштабу | | |
| Зручність внесення змін | | |
| Придатність для подальшої роботи в CAD | | |

### Зміст звіту

1. Тема, мета, обране завдання на проєктування.
2. Фотографія ескізу на папері.
3. Знімки екрана обох варіантів рішення у VR, зовні та зсередини.
4. Перелік змін, внесених після огляду зсередини, з поясненням причин.
5. Результат експорту: знімок моделі, відкритої в SketchUp або Revit.
6. Порівняльна таблиця способів роботи.
7. Висновки: на якій стадії проєктування ескізування у VR доцільне.

### Контрольні питання

1. Чим ескізування у VR відрізняється від ескізування на папері?
2. Чому важливо ставити у сцену об'єкт відомого розміру?
3. Чому пропорції, прийнятні на папері, можуть виявитися невдалими при огляді зсередини?
4. Що втрачається при експорті моделі з Gravity Sketch?
5. На якій стадії проєктування доцільно застосовувати такий інструмент?
