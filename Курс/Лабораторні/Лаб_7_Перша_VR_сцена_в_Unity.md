# Лабораторна робота № 7
## Перша VR-сцена в Unity та прості скрипти

**Тема:** 7 (Ігрові рушії)
**Тривалість:** 4 години

### Мета роботи

Створити власну віртуальну сцену на основі будівельної моделі, налаштувати переміщення користувача за готовим шаблоном та написати найпростіші скрипти, що додають сцені інтерактивності.

### Обладнання та програмне забезпечення

- Комп'ютер, шолом Meta Quest 3, кабель Link
- Unity (версія з довготривалою підтримкою) з модулями XR Plugin Management, OpenXR, XR Interaction Toolkit
- Модель із роботи № 3 або № 5 у форматі FBX

### Короткі теоретичні відомості

Візуалізатори на кшталт Enscape показують модель, але не дозволяють із нею взаємодіяти. Ігровий рушій потрібен тоді, коли від віртуального середовища вимагається поведінка: щось натискається, перемикається, рахується. XR Interaction Toolkit містить готові компоненти, завдяки яким робоча VR-сцена збирається без програмування, а скрипти потрібні лише для власної логіки — і це справді короткі скрипти на 10–15 рядків.

### Порядок виконання роботи

**Завдання 1. Створення проєкту**

1. Створити проєкт Unity (шаблон 3D).
2. Через менеджер пакетів підключити XR Plugin Management, увімкнути OpenXR і профіль Meta Quest.
3. Підключити XR Interaction Toolkit і встановити зразки (Samples) із готовими налаштуваннями контролерів.

**Завдання 2. Імпорт моделі**

4. Імпортувати файл FBX.
5. Перевірити масштаб: поставити поруч об'єкт заввишки 1,75 м. За потреби виправити коефіцієнт масштабування.
6. Перевірити орієнтацію та положення відносно початку координат.
7. Призначити матеріали основним поверхням: підлозі, стінам, стелі, світлопрозорим конструкціям.
8. Налаштувати напрямлене світло як сонце.

**Завдання 3. Налаштування користувача та переміщення**

9. Додати у сцену XR Origin — камеру шолома й два контролери.
10. Додати колайдери на підлогу та стіни, щоб користувач не провалювався й не проходив крізь конструкції.
11. Додати область телепортації на підлогу, налаштувати телепортацію на один контролер.
12. Налаштувати поворот ривками на другий контролер.
13. Перевірити роботу в шоломі.

**Завдання 4. Скрипт перший: підсвічування елемента**

14. Створити скрипт, який змінює колір елемента, коли на нього наведено промінь контролера:

```csharp
using UnityEngine;

public class Highlight : MonoBehaviour
{
    public Color highlightColor = Color.yellow;

    private Renderer rend;
    private Color baseColor;

    void Start()
    {
        rend = GetComponent<Renderer>();
        baseColor = rend.material.color;
    }

    public void OnHoverEnter()
    {
        rend.material.color = highlightColor;
    }

    public void OnHoverExit()
    {
        rend.material.color = baseColor;
    }
}
```

15. Додати скрипт до кількох елементів моделі й прив'язати методи до подій компонента взаємодії.

**Завдання 5. Скрипт другий: показати або сховати розділ моделі**

16. Створити скрипт, що вмикає й вимикає групу об'єктів (наприклад, інженерні мережі):

```csharp
using UnityEngine;

public class ToggleLayer : MonoBehaviour
{
    public GameObject layer;

    public void Toggle()
    {
        layer.SetActive(!layer.activeSelf);
    }
}
```

17. Згрупувати елементи моделі за розділами: архітектура, конструкції, мережі.
18. Створити у сцені три віртуальні кнопки, кожна з яких перемикає свій розділ.

**Завдання 6. Скрипт третій: лічильник оглянутих приміщень**

19. Створити скрипт, що рахує, у скількох приміщеннях побував користувач:

```csharp
using UnityEngine;

public class RoomCounter : MonoBehaviour
{
    public static int visited = 0;

    private bool counted = false;

    void OnTriggerEnter(Collider other)
    {
        if (!counted && other.CompareTag("Player"))
        {
            counted = true;
            visited++;
            Debug.Log("Оглянуто приміщень: " + visited);
        }
    }
}
```

20. Розмістити в кожному приміщенні невидимий об'єм із увімкненим режимом тригера й додати до нього скрипт.
21. Вивести значення лічильника на віртуальну панель у сцені.

**Завдання 7. Перевірка та продуктивність**

22. Перевірити роботу всіх трьох скриптів у шоломі.
23. Увімкнути вікно статистики, зафіксувати кількість трикутників, викликів відмальовування та частоту кадрів.
24. За потреби виконати оптимізацію й занести результат до таблиці «до / після».

### Зміст звіту

1. Тема, мета, версії програмного забезпечення.
2. Етапи створення сцени зі знімками екрана.
3. Виявлені помилки імпорту моделі та способи їх усунення.
4. Тексти трьох скриптів із поясненням призначення кожного рядка.
5. Знімки екрана роботи кожного скрипта.
6. Таблиця показників продуктивності до та після оптимізації.
7. Висновки: які задачі вимагають рушія, а для яких достатньо візуалізатора.

### Контрольні питання

1. Що дає ігровий рушій порівняно з візуалізатором?
2. Для чого потрібен колайдер?
3. Що таке XR Origin і які компоненти він містить?
4. Чому телепортація зменшує ймовірність кіберхвороби?
5. Поясніть призначення методів Start і OnTriggerEnter у ваших скриптах.
6. Що таке OpenXR?
